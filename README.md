# ML compiler plan

Nine-month plan from linked lists to an LLVM compiler and a CUDA matrix multiply.
Open `index.html` through GitHub Pages (or `python3 -m http.server`) to see progress.

- `progress.json`: the ids of finished items. This is the source of truth.
- `LOG.md`: one line per day about what I did.

## Update routine
1. Open the page, tick what you finished, click "Copy progress.json".
2. Paste it over `progress.json`.
3. Add a line to the top of `LOG.md`.
4. `git add . && git commit -m "Day N: <what you did>" && git push`
